## How React Starts

I learned that `index.html` contains an element with ID `root`. The `main.tsx` file finds this element and uses React to render the `App` component inside it.

```tsx
createRoot(document.getElementById(`root`)!).render(
    <StrictMode>
        <App />
    </StrictMode>,
)
```

`createRoot` connects React to the HTML page. `<App />` tells React with component to display.

`StrictMode` helps find possible problems during development. The `!` after `getElementById('root')` tells TypeScript that I expect the root element to exist.

## Components and JSX

I learned that a React component is a function that returns JSX.

```tsx
function Welcome() {
    return (
        <section>
            <h1>Welcome to C-BEEMS</h1>
            <p>Supporting Indian immigrant parents in Australia.</p>
        </section>
    )
}
```

JSX looks similar to HTML, but it has some differences. It uses `className` instead of `class`, and JavaScript values are placed inside curly brackets.

```tsx
<h1>{title}</h1>
<img src={heroImg} alt="C-BEEMS introduction" />
```

React component names start with a capital letter. A component can be exported from one file and imported into another file.

## State and Events

The Vite template includes a counter:

```tsx
const [count, setCount] = useState(0)
```

`count` stores the current value, while `setCount` changes it. The starting value is `0`.

```tsx
<button onClick={() => setCount((count) => count + 1)}>
    Count is {count}
</button>
```

When the button is clicked, the state changes and React updates the displayed number.

## CSS

I learned that `index.css` contains general website styles, while `App.css` contains styles currently used by the App component.

CSS classes use a dot:

```css
.hero {
    position: relative;
}
```

They are connected to JSX with `className`:

```tsx
<section className="hero">
```

The template also uses CSS variables:

```css
:root {
    --text: #6b6375;
    --bg: #fff;
}
```

CSS variables make colours and other design values easier to reuse.

I also saw a media query:

```css
@media (max-width: 1024px) {
    font-size: 16px;
}
```

A media query changes the design based on the screen size and is useful for responsive websites.
